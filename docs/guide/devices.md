# Supported devices

| Device | Type | Status | What Sipquel does with it |
|---|---|---|---|
| BOOKOO Themis | Scale | **Supported** | Live weight and flow, dose capture, tare, pour guidance |
| BOOKOO Motto80 | Grinder | **Supported** | Reads and sets the grind size and speeds, times the grind, presets |
| Gaggiuino | Espresso machine | **Supported** | Live pressure, flow, temperature and the shot curve |
| Fellow Stagg EKG | Kettle | Experimental | Reads the kettle; still being qualified |
| GaggiMate | Espresso machine | Coming | Planned |
| Decent Espresso | Espresso machine | Coming | Planned |

"Supported" means it works in the beta. "Experimental" means it is there but still being tested. "Coming" means it is planned and not in the beta yet.

Missing your gear? Say so when you [join the beta](/guide/beta).
